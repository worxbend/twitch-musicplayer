Your MP3s.
On air.
All night.

A self-hosted 24/7 lofi radio for your stream. Point it at a folder of music you're allowed to broadcast, and it picks, crossfades and paints every track into an OBS scene. No subscription, no algorithm, no stranger's playlist.

Get it running Read the code on GitHub

Built for the stream, not the playlist.

A Go backend runs the station. A SolidJS and PixiJS frontend plays it, draws it and hands it to OBS. Everything stays on your machine.

It never goes quiet
Equal-power crossfades between tracks. Broken files get retried, then skipped. Dropped connections reconnect on their own.
Drop files in, they're on the air
The library watches your folder. New MP3s are queued once the copy finishes; deleted ones leave quietly; retagged ones update live.
Eight scenes that actually listen
Audio-reactive WebGL visuals, each with a transparent overlay twin and colour ramps. Paste the URL into an OBS browser source and you're done.
Chat knows what's playing
A transparent now-playing overlay that can show the album cover, a text file for OBS Text sources, and /v1/now-playing.txt (with an ?idle= line for quiet moments) for Nightbot or StreamElements.
Cover art comes along
Embedded MP3 covers show in the track deck, the now-playing overlay and your OS media controls.
No repeats, no artist pile-ups
Every song plays once per cycle, and the same artist never plays twice in a row. Play history survives restarts.

Run the queue like you own the booth.

Search your library, queue a track, play one right now, move it up or down, or skip the current song. Recently played sits right there, so you can answer "what was that?" in chat without guessing.

Hit Don't play this and a song leaves rotation. The Blocked list lets you allow it again.

It works from the keyboard, and screen readers hear every status change.

On air in three steps

You need Docker and a folder of MP3s.

  1. Clone it

    git clone https://github.com/worxbend/twitch-musicplayer.git
cd twitch-musicplayer

  2. Point it at your music

    MUSIC_DIR=~/Music docker compose up -d --build

  3. Add it to OBS

    Open http://localhost:3000/scenes, pick a scene, copy its overlay URL into a browser source. The console lives at /admin.

Running it on another machine? Set BASE_URL and ALLOWED_ORIGINS first. The deployment guide walks through it.
